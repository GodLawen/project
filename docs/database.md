# Схема базы данных трекера привычек

Для создания схемы нужен PostgreSQL и пустая база с правом создания таблиц. Из корня репозитория выполните:

```bash
psql --dbname=habittrack --set=ON_ERROR_STOP=1 --single-transaction --file=db/schema.sql
```

При ошибке транзакция откатится. Скрипт предназначен для первичного создания таблиц.

| Таблица | Назначение и ограничения |
|---|---|
| users | Один пользователь на уникальный telegram_id. Часовой пояс по умолчанию UTC. |
| habits | Привычки связаны с пользователем через user_id. Хранят название, время напоминания и признак активности. |
| checkins | Отметки связаны с привычкой через habit_id. Ограничение UNIQUE(habit_id, check_date) защищает от двух отметок за один день. |

Удаление пользователя каскадно удаляет его привычки и связанные отметки. Проверить результат можно командой `psql --dbname=habittrack -c '\dt'`.
